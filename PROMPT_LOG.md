## Задание 2: Добавление буферизации и пакетной записи

**Инструмент:** Claude (claude.ai)

Накапливать N=20 записей или ожидать T=2s перед записью в файл.
Цель — снизить количество операций ввода-вывода. Без комментариев в коде.

**Что сделано:**
1. Добавлена структура `BatchWriter` — инкапсулирует канал, горутину-воркер и статистику
2. Метод `loop()` читает из канала и флашит батч при двух условиях:
   - накоплено `batchSize=20` записей (немедленный flush)
   - сработал `time.Ticker` с `flushTimeout=2s` (flush по таймауту)
3. При закрытии канала (`bw.Close()`) — финальный flush остатка
4. Буфер канала = `batchSize*2` — исключает блокировку продюсеров
5. Результат: 168 записей → 9 флашей вместо 168 операций записи (экономия ~95%)

## Задание 3: Реализация graceful shutdown

**Инструмент:** Claude (claude.ai)

**Промпт:**
Добавь в Go-сборщик обработку сигналов SIGINT/SIGTERM. При завершении сборщик должен
дообработать текущие данные, записать буфер в файл и корректно закрыть соединения.
Без комментариев в коде.

**Что сделано:**
1. Добавлен `context.WithCancel` — контекст передаётся в `collectSensorData` и
   `collectWeatherData`, оба цикла проверяют `ctx.Done()` на каждой итерации
2. Горутина-слушатель перехватывает `os.Signal` через `signal.Notify` на `SIGINT`/`SIGTERM`
   и вызывает `cancel()`

   в `BatchWriter`, затем `bw.Close()` выполняет финальный flush буфера
4. `sync.WaitGroup` гарантирует ожидание всех горутин перед выходом из `main`
5. Финальное сообщение различается: graceful shutdown vs нормальное завершение
