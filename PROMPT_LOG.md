## Задание 2: Добавление буферизации и пакетной записи

**Инструмент:** Claude (claude.ai)

**Промпт:**
Модифицируй сборщик Go из задания 1: добавь канал с буфером и пакетную запись.
Накапливать N=20 записей или ожидать T=2s перед записью в файл.
Цель — снизить количество операций ввода-вывода. Без комментариев в коде.

**Что сделано:**
1. Добавлена структура `BatchWriter` — инкапсулирует канал, горутину-воркер и статистику
2. Метод `loop()` читает из канала и флашит батч при двух условиях:
   - накоплено `batchSize=20` записей (немедленный flush)
   - сработал `time.Ticker` с `flushTimeout=2s` (flush по таймауту)
3. При закрытии канала (`bw.Close()`) — финальный flush остатка
4. Буфер канала = `batchSize*2` — исключает блокировку продюсеров
5. Результат: 168 записей → 9 флашей вместо 168 операций записи (экономия ~95%)

### Итого

- Время: ~5 мин
